# numworks-python-framework
Framework for python on the Numworks graphing calculator to make GUI's (description subject to change)

# Using the repository yourself
To use this repo, depending on your system you'll want to make a virtual environment. But regardless, you'll need the package list of requirements.txt which is the result of `pip freeze`. This contains all the packages needed to be installed with pip. In VS Code you can also just use the Python extension(s) to create a custom virtualenv, in which you will be able to choose something with dependencies in the choice name, where you can then put in requirements.txt to have VSc install the requirements at the setup.
